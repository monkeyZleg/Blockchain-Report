# Screenshot & asset folder

Drop screenshots here using the filenames already referenced in `../README.md` (e.g. `7.1-signup.png`, `7.9-borrow-confirm.png`) and they will appear automatically wherever that figure is referenced — no need to edit the markdown.

Suggested capture settings: browser window ~1440px wide, light/dark theme consistent across all shots, MetaMask popups included where a screenshot's caption asks for them.
